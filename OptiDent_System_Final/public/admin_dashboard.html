Step-by-Step: How to get Google Service Account JSON
  1. Open Google Cloud Console and create or select your project.
  2. Navigate to APIs & Services > Library → search for Google Calendar API and click Enable.
  3. Go to APIs & Services > Credentials → click + Create Credentials > Service Account.
  4. Enter a name (e.g. optident-calendar), click Create and Continue, and assign role Project > Editor.
  5. Click on the newly created Service Account → switch to the Keys tab → click Add Key > Create new key > JSON.
  6. A .json key file will download to your device. Open it in Notepad, copy the entire JSON text, and paste it into the box above.
  7. Important: Open Google Calendar with account edjamenf@gmail.com → Settings → Share calendar with the Service Account email address (e.g. ...iam.gserviceaccount.com) with permission "Make changes to events".

Step-by-Step: How to get 16-Char Gmail App Password
  1. Log in to your clinic Google Account at myaccount.google.com.
  2. Click on Security on the left-side navigation menu.
  3. Under "How you sign in to Google", verify that 2-Step Verification is switched ON.
  4. Search for "App passwords" in the top search bar (or visit myaccount.google.com/apppasswords).
  5. Under "App name", type OptiDent System and click Create.
  6. Google will display a 16-character password (e.g. emuv fyqh uyya fpku).
  7. Copy the 16 characters and paste into the App Password box above (spaces are removed automatically).

Step-by-Step: How to get Google reCAPTCHA v2 Secret Key
  1. Go to the Google reCAPTCHA Admin Console.
  2. Enter a Label such as OptiDent Dental Clinic.
  3. Under reCAPTCHA type, select reCAPTCHA v2 → select "I'm not a robot" Checkbox.
  4. Under Domains, enter localhost and 127.0.0.1 (plus your server domain or IP).
  5. Accept the Terms of Service and click Submit.
  6. Copy both the Site Key and the Secret Key (each starts with 6L...) into the two fields above. They only work as a pair.

Step-by-Step: How to get Google OAuth 2.0 Web Client ID
  1. Open Google Cloud Console → APIs & Services > Credentials.

  3. Click + Create Credentials > OAuth client ID.
  4. Select Web application as the Application type.
  5. Under Authorized JavaScript origins, add http://localhost:3000 and http://127.0.0.1:3000.
  6. Under Authorized redirect URIs, add http://localhost:3000 and http://127.0.0.1:3000.
